# Collector v0.3.3 and Helm Chart 0.3.5

Released 2026-10-15. This release makes `SHA256SUMS` and `sbom-index.json` verifiable
with build-provenance attestations, aligns the deployment and LiteLLM guides with
fleetdiff v0.8.0, includes a tested OpenInference / OpenLLMetry normalization
recipe and source-specific own-traffic guidance, and updates runtime dependencies.

## What You Get

- **Verify release metadata.** Download `provenance.jsonl` with `SHA256SUMS`
  and `sbom-index.json`, and verify both subjects against this repository's
  release workflow and exact tag, rejecting self-hosted runners. The release
  workflow performs these checks before uploading metadata.
- **Use aligned guides.** The [deployment](../DEPLOYMENT.md),
  [summary export](../SUMMARY_EXPORT_HELM.md), and
  [LiteLLM](../../examples/integrations/litellm/README.md) guides use fleetdiff
  v0.8.0. The opt-in summary-history example retains 32 one-minute windows,
  enough for a 24-window baseline and two recent windows.
- **Connect more trace sources.** The
  [OpenInference / OpenLLMetry recipe](../../examples/integrations/genai-normalizer/README.md)
  normalizes synthetic spans through contrib v0.162.0 on a separate sketch
  branch feeding collector v0.3.2. The
  [own-traffic guide](../../README.md#run-it-on-your-traffic) lists tested input
  routes before the synthetic demo.
- **Keep valid summaries when an export fails.** With llm-sketchkit v0.3.0,
  repeated export of nonempty observations within the same clock tick at startup
  or a new-window boundary fails explicitly and retains the previous valid file.
  Retained measurements can be exported after time advances. Readers also reject
  protobuf groups. Runtime dependencies include Prometheus common v0.72.1.
- **Check team token budgets without stale-instance burn.** The
  [token-budget alert recipe](../../examples/prometheus/token-budget/README.md)
  includes multiwindow burn-rate rules and user-supplied team budgets.
  Each window excludes stale instances before team aggregation, so an active
  peer cannot retain their historical rates. The fix is covered by 23 rule
  cases and real OTLP replay.

## Version Selection

Chart **0.3.5** selects collector **0.3.3** through `appVersion`.
`builder.yaml` uses `0.3.3-dev` for source builds; the release workflow supplies
`VERSION=0.3.3` from the runtime tag for the image and connector inventory.
The chart's `image.tag` and `image.digest` overrides keep their existing
precedence. CI, release verification and the digest-pinned Docker build already
use Go **1.26.9**. The runtime release publishes and signs chart 0.3.5 as well;
verify its chart signature against `release.yml@refs/tags/v0.3.3`.

## Limits

Standalone/custom builds moving from x/text v0.41.0 to v0.42.0 change eight of
8,254 pinned identities for U+11F41 combining-mark cases. Upgrade affected
producers at a window boundary and keep old/new windows separate; follow the
[migration procedure](../UPGRADING.md#sketchkit-030-in-this-source-candidate).
The distribution moves from v0.42.0 to v0.43.0 with all 8,254 unchanged.
Wire formats and accounting IDs cannot detect this boundary.

Accounting, canonical encodings and chart defaults stay unchanged; 32-window
retention is opt-in. LiteLLM callback scope remains 1.102.1; normalizer evidence
uses synthetic spans and the processor is outside the default distribution.
Metadata attestations cover this release, not earlier artifacts; the SBOM index
is a provenance subject, not an SBOM predicate. OCI publication is not rolled
back if later metadata verification fails.
