# Collector v0.3.3 and Helm Chart 0.3.5 (Unreleased Draft)

This release is planned to make `SHA256SUMS` and `sbom-index.json` verifiable
with build-provenance attestations, align the deployment and LiteLLM guides with
fleetdiff v0.8.0, and include a tested OpenInference / OpenLLMetry normalization
recipe and source-specific own-traffic guidance.

## What You Get

- **Verify release metadata.** Download `provenance.jsonl` with `SHA256SUMS`
  and `sbom-index.json`, and verify both subjects against this repository's
  release workflow and exact tag, rejecting self-hosted runners. The release
  workflow performs these checks before uploading metadata.
- **Use aligned guides.** The [deployment](../DEPLOYMENT.md),
  [summary export](../SUMMARY_EXPORT_HELM.md), and
  [LiteLLM](../../examples/integrations/litellm/README.md) guides use fleetdiff
  v0.8.0. The opt-in summary-history example retains 32 one-minute windows,
  enough for a 24-window baseline and two recent windows.
- **Connect more trace sources.** The
  [OpenInference / OpenLLMetry recipe](../../examples/integrations/genai-normalizer/README.md)
  normalizes synthetic spans through contrib v0.162.0 on a separate sketch
  branch feeding collector v0.3.2. The
  [own-traffic guide](../../README.md#run-it-on-your-traffic) lists tested input
  routes before the synthetic demo.

## Version Selection

Chart **0.3.5** selects collector **0.3.3** through `appVersion`.
`builder.yaml` uses `0.3.3-dev` for source builds; the release workflow supplies
`VERSION=0.3.3` from the runtime tag for the image and connector inventory.
The chart's `image.tag` and `image.digest` overrides keep their existing
precedence. CI, release verification and the digest-pinned Docker build already
use Go **1.26.9**; this preparation leaves that toolchain unchanged.

## Scope And Release Checks

This is an unpublished preparation draft. Collector **v0.3.2** / chart
**0.3.4** remains the verified install pair in the guides. Before tagging,
land and review the separate documentation change and
[PR #85](https://github.com/llm-measurement/otelcol-genai-sketches/pull/85),
confirm chart 0.3.5 is unused, replace `TAGDAY (pending)` in the changelog with
the actual tag-day date in `YYYY-MM-DD` format, and reconcile these notes with
the final reviewed commit. Run the full release checks, then verify the actual
published image/chart digests, signatures and provenance after separately
authorized publication.

Runtime behavior, dependencies, identity, accounting, wire format, chart defaults
and existing image/chart attestations are unchanged by this release-preparation
candidate. Retention changes apply only to the opt-in example; earlier
short-history Kubernetes evidence stays labeled. LiteLLM callback scope remains
1.102.1. Normalizer evidence covers synthetic spans rather than live SDKs, and
the processor remains outside the default distribution.

The SBOM index is a provenance subject, not an SBOM predicate. These checks do
not retroactively attest v0.3.2 metadata. OCI publication happens before metadata
verification and is not rolled back if a later check fails. Actual hosted-runner
signing and published-asset verification remain release gates; local preparation
checks alone do not establish them. No release digest is assigned in this draft.
