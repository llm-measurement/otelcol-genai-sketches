# Collector v0.7.3

This security maintenance release keeps Go 1.26.11 for
[GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859) and updates the runtime
distribution to `golang.org/x/crypto` v0.59.0 for
[GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932). The resolved companion
versions are x/sys v0.50.0, x/term v0.48.0 and x/text v0.44.0. Collector
behavior and configuration defaults are unchanged.

The signed v0.7.2 tag was created, but that release was never published. Its
stripped binary matched the affected x/crypto module version. Review of the
exact generated Linux amd64 and arm64 distributions found no affected OpenPGP
packages in either import graph. The dependency update removes that module
match; the binary scan still blocks publication. The release also runs a
source package scan for each generated Linux distribution. See the
[OpenVEX procedure](../OPENVEX.md) for the evidence and review requirements.

The runtime release includes intermediate Helm chart `0.7.4-rc.1`. Stable
chart `0.7.4` follows separately and pins the published collector image index
digest. The v0.7.2 tag and its recorded chart version are not reused.
