# Security fix: updates two dependencies with published advisories

Collector v0.7.1 is a patch release with no breaking changes from v0.7.0.

## Dependency Fixes

- `klauspost/compress` v1.20.2 addresses
  [GO-2026-6865](https://pkg.go.dev/vuln/GO-2026-6865).
- `golang.org/x/net` v0.62.0 addresses CVE-2026-78661 /
  [GO-2026-6860](https://pkg.go.dev/vuln/GO-2026-6860).

The earlier generated-distribution reachability scan reported GO-2026-6865 as
reachable. For GO-2026-6860, the reachability scan reported no reachable calls;
the production-image inventory scan still flagged the affected x/net version.
These are advisory and scan findings, not a claim of demonstrated exploitation.

Configuration, accounting and summary contracts, and feature defaults are
unchanged. The existing v0.7.0 upgrade requirements still apply.

## Release Evidence

The normal `release.yml` workflow builds the multi-architecture image and
publishes image signatures, attested `SHA256SUMS`, the SBOM index and OpenVEX
evidence. Verify the exact release tag, source commit, image digest, signing
identity and attestation subjects.

The runtime release includes intermediate chart 0.7.2-rc.1 with appVersion 0.7.1.
Stable chart 0.7.2 follows after the image exists, pins its multi-architecture
index digest and uses the separate `chart-release.yml` signing identity.

Independent signature, attestation, digest and outsider-install verification
precedes changes to README or site version pointers.
