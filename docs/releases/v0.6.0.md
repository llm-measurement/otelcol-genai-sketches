# Collector v0.6.0 and Helm Chart 0.6.0

October 18, 2026 (Eastern Time). Use one opt-in model-usage producer for a
LiteLLM gateway serving both Anthropic Messages and OpenAI Chat or Responses.
Pair it with fleetdiff v0.11.0. Existing request-model attribution stays the
default.

## What You Get

- **One profile for four tested paths.** `litellm-1.104.0-v2` combines
  nonstreaming Chat, streaming Chat, Responses and Messages. Exact native
  call-type and route markers select the existing rule for each attempt.
- **A narrow Messages profile.** `litellm-1.104.0-messages-v1` uses the selected
  model and verifies a present response model for nonstreaming requests.
  Streaming Messages uses only the selected model, because the exported response
  model is an echo rather than independent confirmation.
- **An unchanged v1 contract.** The existing three-path combined profile and
  standalone contracts retain their identifiers and behavior. Defaults, metrics,
  base accounting and summary formats are unchanged.

## Upgrade

1. Use fleetdiff v0.11.0 as the downstream reader.
2. Deploy collector v0.6.0 or chart 0.6.0 with appVersion 0.6.0, keeping
   model-usage identity opt-in until the configuration is approved.
3. Choose a [profile and exact model maps](../MODEL_USAGE_SUMMARIES.md).
   LiteLLM requires the stock `otel` callback and
   `OTEL_SEMCONV_STABILITY_OPT_IN=gen_ai_latest_experimental`.
4. Obtain the contract identifier from a controlled producer using those maps,
   and pass it explicitly to fleetdiff. Change profiles at a window boundary;
   keep v1, v2 and standalone-profile windows separate.

The runtime release publishes the image and chart together. Verify both against
`release.yml@refs/tags/v0.6.0`; there is no separate chart tag. Follow
[deployment verification](../DEPLOYMENT.md) and [rollback guidance](../UPGRADING.md).

## Limits

These profiles describe pinned LiteLLM 1.104.0 telemetry. Streaming Chat and
Messages identify the gateway-selected model, not a confirmed provider snapshot.
Unknown or conflicting mappings remain unpriced. A model identity does not prove
completion or final usage, and missing usage stays missing. Tests use mock
provider evidence and real OTLP through the collector, not account-authenticated
coding-agent traffic. Collector stability remains alpha; pin exact versions and
image digests.
