# Count Workflow And Framework Roots

Collector v0.8.0 adds an opt-in root-invocation count for applications whose
entry span is a workflow or a framework runner. It targets OpenTelemetry
GenAI semantic conventions [v0.1.0](https://github.com/open-telemetry/semantic-conventions-genai/releases/tag/v0.1.0),
at revision `d0e74ba6c48bcc4ded473b1828a8212f06b23753`.

## Root Invocations

```yaml
root_invocations:
  enabled: true
  operations: [invoke_agent, invoke_workflow, invoke_runner]
```

The new `gen_ai_sketch_root_invocations_total` metric counts a parentless
INTERNAL span in the configured operation set. The enabled defaults include
`invoke_agent` and `invoke_workflow`. Existing bounded slices apply to the
new metric; it adds no metric label. The original agent-run metric keeps
its existing definition.

Summary exports put the optional count and its root-operation definition
in a versioned `root_invocations.v1.*` counter group. This composes the
existing summary measurement contract: different operation sets, or enabled
versus disabled measurements, reject comparison and merging. The base
accounting fingerprint is unchanged. With the option off, the new metric
and summary group are absent.

See [configuration](../CONFIGURATION.md) and
[semantic-convention compatibility](../SEMANTIC_CONVENTIONS.md) for the
bounded operation list, remote invocation roles and counting limits.

## Current Token Names

The connector reads the current cache-read, cache-write and reasoning
attributes, while preserving legacy cache-creation, prompt-token and
completion-token aliases. Workflows use `gen_ai.agent.name`. Embeddings
remain in the default billed-token operation filter even though the
conventions classify them separately from inference.

Model-operation filtering keeps agent rollups out of inference totals.
Calls without usage are counted separately as missing. The linked semantic
compatibility guide explains how this complements upstream usage counters
and per-operation histograms.

independently verified image index through the separate chart-release
