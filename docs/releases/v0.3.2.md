# Collector v0.3.2 and Helm Chart 0.3.4

This patch brings llm-sketchkit v0.2.3 hardening to the collector and connector
module: parser allocation limits, more efficient summary combination, and safer
secret and error diagnostics. Chart 0.3.4 selects collector v0.3.2 by default.

## Compatibility

This upgrade preserves each build's existing identities: the standalone
connector retains `golang.org/x/text` v0.41.0, and the distribution retains
v0.42.0. Both dependency graphs are checked against their pinned identity
corpora. Summary wire format, token accounting and the base accounting
fingerprint are unchanged. Sketchkit v0.3.0 remains a separate migration.

Operators moving from collector v0.3.1 keep the same normalization behavior.
Those moving from v0.3.0 or earlier should follow the
[v0.3.1 identity guidance](../UPGRADING.md#text-identities-in-v031), including
keeping affected old windows separate or rebuilding them. The standard
[restart behavior](../UPGRADING.md#rollout-behavior) still applies.

## Included Updates

- Reviewed Go dependencies, including gRPC v1.84.0, with Go 1.26.9 and the
  existing x/net and crypto security pins.
- Identity-drift regression coverage for standalone and distribution builds.
- An offline event-time replay example for one lab's released Claude Code and
  Codex records. It requires `-tags tracelab_replay`; replay code is excluded
  from default collector builds and images.
- Updated component, deployment and integration documentation.

## Install And Verify

- Image: `ghcr.io/llm-measurement/otelcol-genai-sketches:0.3.2`.
- Chart: `oci://ghcr.io/llm-measurement/charts/otelcol-genai-sketches`, version
  `0.3.4`.
- Connector module: `github.com/llm-measurement/otelcol-genai-sketches/connector/genaisketchconnector@v0.3.2`.

Use the release's image and chart digests, signatures and provenance following
[Deployment](../DEPLOYMENT.md). The release workflow checks both published
architectures through the summary-export and private-ranking integration tests.
The chart and runtime versions advance independently; chart 0.3.4 retains
existing values and opt-in defaults.
