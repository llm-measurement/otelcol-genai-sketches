# Collector v0.5.0 and Helm Chart 0.5.0

October 17, 2026 (Eastern Time). Attribute per-model usage to approved model
identities instead of assuming a dynamic route alias always selects one model.
Pair this release with fleetdiff v0.11.0 for local routing investigation and
repricing. Existing request-model attribution remains the default.

## What You Get

- **One profile for mixed LiteLLM traffic.** `litellm-1.104.0-v1` covers
  nonstreaming Chat, streaming Chat and Responses under one producer contract.
  Exact native route and call-type markers select the existing per-path rules.
- **Explicit model attribution.** Version-pinned profiles also cover
  agentgateway 1.6.0 and Envoy AI Gateway 1.1.0 Chat. Approved maps keep unknown,
  ambiguous or conflicting identities in unpriced buckets, without copying raw
  model names into summary files.
- **An opt-in upgrade.** Existing metrics, base accounting, disabled summary
  bytes and summary formats are unchanged. Individual LiteLLM profiles remain
  available; the combined profile does not change their contracts.

## Upgrade

1. Upgrade downstream readers to the paired fleetdiff v0.11.0 release.
2. Deploy collector v0.5.0 or chart 0.5.0 with appVersion 0.5.0, keeping
   served identity disabled until the configuration is approved.
3. Choose a [profile and exact model maps](../MODEL_USAGE_SUMMARIES.md).
   LiteLLM requires its stock `otel` callback and
   `OTEL_SEMCONV_STABILITY_OPT_IN=gen_ai_latest_experimental`.
4. Obtain the contract ID from a controlled producer using that approved
   configuration, and pass it explicitly to fleetdiff. Keep old and new contract
   windows separate; switching profiles or maps changes the contract.

The runtime release publishes the image and chart together. Verify both against
`release.yml@refs/tags/v0.5.0`; there is no separate chart tag. Follow
[deployment verification](../DEPLOYMENT.md) and [rollback guidance](../UPGRADING.md).

## Scope

LiteLLM streaming Chat identifies the gateway-selected model, not a confirmed
provider snapshot. Default nonstreaming Auto Routing alias echoes remain
unpriced; preserve and explicitly map provider response names as described in
the guide. Anthropic Messages is not supported by these profiles. Model identity
does not prove completion or final usage, and missing usage remains missing.
Collector stability remains alpha; pin exact versions and image digests.
