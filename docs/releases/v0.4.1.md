# Collector v0.4.1 and Helm Chart 0.4.1

Released 2026-10-16. Keep per-model input, output and cache token splits in
optional summary files, then re-price covered usage with fleetdiff v0.10.0.
Export stays off until explicitly enabled; existing metrics and disabled summary
bytes retain their behavior.

This completes the release after v0.4.0's image was published but its chart and
release assets were not. The OpenVEX extraction step now selects each immutable
platform manifest separately, avoiding a Docker image-store collision between
architectures. Use v0.4.1 for the complete, verified install pair; v0.4.0's tag
and image are unchanged. Collector processing behavior is unchanged from v0.4.0.

## What You Get

- **Re-price usage without retaining requests.** The optional `model_usage` v1
  block contains bounded per-model reported totals, request counts and complete
  input/output/cache cohorts. A versioned input histogram retains per-request
  extrema for price-tier checks. Missing usage remains missing.
- **Choose what model names leave the pipeline.** An explicit approved map
  translates observed names to public model IDs. Unmapped and reserved buckets
  remain visible as unpriced coverage, without passing raw model names through.
- **Keep snapshots consistent.** Enabled exports use the existing model slice
  and processing-time windows. Batch updates are atomic under model and byte
  limits; replay-safe readers select the latest cumulative snapshots.
- **Verify the vulnerability assessment.** A release-specific OpenVEX statement
  records the absence of the affected OpenPGP package from the published
  collector's import graphs for GO-2026-5932. The statement is checksummed and
  attested; the module-level stripped-binary warning is not suppressed.

## Upgrade Order

1. Upgrade downstream fleetdiff readers to v0.10.0 or later.
2. Deploy collector v0.4.1, or chart 0.4.1 with appVersion 0.4.1, leaving
   model usage disabled until all readers are ready.
3. Configure the [approved model map](../MODEL_USAGE_SUMMARIES.md) and explicitly enable model-usage export.
   Give the reader the matching expected contract identifier.

The shared format comes from llm-sketchkit v0.4.0. Fleetdiff uses its v0.2.4
identity-preserving backport; both read the same extension. The runtime workflow
publishes and signs the image and chart together. Verify both against
`release.yml@refs/tags/v0.4.1`; there is no separate chart tag.

## Limits

Older readers reject enabled `model_usage`; enabling it is a reader compatibility
boundary, not an identity migration. Model totals contain no key/team
intersections. Unknown model prices, incomplete splits and origin-unknown zero
usage cannot be re-priced. The current price file supports one applicable input
tier per model, not invented higher-tier rates. OpenVEX applies to the identified
release artifacts, not custom builds that add other components. Collector
stability remains alpha; pin exact versions and image digests.
