# Security fix: rebuild with Go 1.26.11

Collector v0.7.2 updates the Go toolchain from 1.26.10 to 1.26.11 for
[GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859) in `net/http`.
The collector code, dependencies, configuration, accounting contracts and
feature defaults are unchanged.

Both v0.7.1 Linux binaries were built with Go 1.26.10 and flagged by
`govulncheck` in binary mode. The v0.7.2 release scans both new binaries
before signing and publishing. Binary scan findings are not evidence of
exploitation.

The release workflow signs the runtime image and attests the checksums, SBOM
index and OpenVEX evidence. It also publishes intermediate chart 0.7.3-rc.1
with appVersion 0.7.2. Stable chart 0.7.3 follows under its separate signing
identity and pins the published multi-architecture runtime digest.
