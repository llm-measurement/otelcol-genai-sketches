# Collector v0.6.2 / Helm chart 0.6.2

This security patch rebuilds the collector with Go 1.26.10 for
[GO-2026-6809 (CVE-2026-111943)](https://pkg.go.dev/vuln/GO-2026-6809).
It includes the reviewed connector dependency and release-pipeline maintenance.

The connector's OpenTelemetry Collector modules `component`, `consumer` and
`pdata` move from 1.68.0 to 1.69.0, and `connector` moves from 0.162.0 to 0.163.0.
This release introduces no breaking changes.

## Security scope

The Go fix adds a denylist in `crypto/x509.Certificate.Verify` for compromised
intermediate certificates. It protects the narrow cases where system trust
stores have not been updated to distrust those certificates. Keep system trust
stores updated as well.

## Install

After publication, select collector v0.6.2 with chart 0.6.2 and verify the
published image and chart digests, signatures, checksums, SBOMs and provenance.
The runtime release publishes the paired chart; no separate chart tag is needed.
